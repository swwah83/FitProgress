# FitProgress — мобильная тестовая версия (PWA)

## Как открыть на телефоне
Самый простой способ:
1. Скачайте ZIP и распакуйте его на компьютере или телефоне.
2. Для установки как приложения разместите папку на HTTPS-хостинге (например, GitHub Pages).
3. Откройте опубликованный адрес в браузере телефона.
4. Android/Chrome: нажмите «Установить» или меню браузера → «Установить приложение».
5. iPhone/Safari: нажмите «Поделиться» → «На экран Домой».

Важно: установка PWA требует HTTPS (или localhost). Если открыть index.html напрямую как файл, приложение запустится, но установка и офлайн-кеширование работать не будут.

## Функции
- Каталог программ тренировок.
- Закрепление выбранной программы в профиле.
- Профиль с личными данными и сохранением в браузере.
- Дневник тренировок, история, график и подсчёт объёма.
- ИИ-помощник в локальном демонстрационном режиме.
- Premium-функции открыты для тестирования.

Данные хранятся локально на устройстве в браузере. Очистка данных браузера удалит локальные записи.
Видеораздел открывает поиск демонстраций на YouTube. ИИ-помощник не подключён к внешней нейросети.
